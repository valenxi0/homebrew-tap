# valenxi0/tap

Homebrew tap for [Nano](https://trynano.app), a free, open source Dynamic Island for your Mac's notch.

```sh
brew install --cask valenxi0/tap/nano
```

Update with `brew upgrade --cask nano`. The cask follows the latest
[Nano release](https://github.com/valenxi0/Nano/releases/latest) automatically.

Requires macOS 14.6 or later on an Apple silicon Mac.
